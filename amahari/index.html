Amazon商品リンク生成を、もっと簡単に

ASIN / URL を貼るだけ。Electron製のデスクトップアプリで Amazon Creators API を手軽に扱えます。

ダウンロード 機能を見る トップページへ

主な機能

ASIN / URL 自動判別

AmazonのURLでもASIN単体でもOK。自動でASINを抽出します。

HTMLテンプレート編集

ブログ貼付用のHTMLを自由にカスタマイズ可能。

画像サイズ調整

Amazon商品画像のサイズをGUIで簡単に変更できます。

安全な認証情報管理

Creators API に必要な以下の情報をアプリ内で保存できます。

  • Credential ID
  • Credential Secret
  • Partner Tag
  • API Version

※ 認証情報はローカル環境にのみ保存されます

Windows向けデスクトップアプリ

Electron製。インストーラーをダウンロードしてすぐ使えます。
